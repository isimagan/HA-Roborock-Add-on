# Roborock Add-ons

A Home Assistant custom integration for additional Roborock entities.

## Prerequisite

Set up Home Assistant's built-in **Roborock** integration first.

## Install with HACS

1. Open HACS and choose **Custom repositories**.
2. Add `https://github.com/isimagan/HA-Roborock-Add-on` as **Integration**.
3. Download **Roborock Add-ons** and restart Home Assistant.
4. Go to **Settings → Devices & services → Add integration**.
5. Search for **Roborock Add-ons** and complete the setup.

No YAML configuration is required.

Planned entities are described in [Sensors to add.md](Sensors%20to%20add.md).
