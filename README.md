# Roborock Add-ons

A Home Assistant custom integration for additional Roborock entities.

## Install with HACS

1. Open HACS and choose **Custom repositories**.
2. Add `https://github.com/isimagan/HA-Roborock-Add-on` as **Integration**.
3. Download **Roborock Add-ons** and restart Home Assistant.

The repository now follows the HACS integration layout. Planned entities are described in [Sensors to add.md](Sensors%20to%20add.md).
